# LiteraSphere

Учебная платформа для репетитора по русскому языку и его учеников.

## Что уже реализовано

- авторизация на ASP.NET Core Identity;
- разделение на роли репетитора и ученика;
- SQL Server в качестве основной БД;
- demo-режим на SQLite для быстрого локального просмотра;
- группы учеников;
- редактор тестов с разными механиками и типами вопросов;
- назначение тестов выбранным группам;
- кабинет ученика с отправкой работ и базовой автопроверкой;
- seed-данные с демо-аккаунтами.

## Демо-аккаунты

- Репетитор: `tutor@literasphere.local` / `Tutor123!`
- Ученик: `ivan@student.local` / `Student123!`

## Запуск

### Быстрый просмотр

В `Development`-режиме проект автоматически использует SQLite и запускается без настройки SQL Server.

1. В каталоге проекта выполните `dotnet restore`.
2. Затем выполните `dotnet run`.

### Работа с SQL Server

1. Измените `DatabaseProvider` на `SqlServer`.
2. Укажите рабочую строку подключения в `ConnectionStrings:DefaultConnection`.
3. Запустите `dotnet run`.

При первом старте приложение создаст схему БД через `EnsureCreated()` и заполнит демо-данными.
